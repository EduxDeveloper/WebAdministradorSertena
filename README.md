# Sertena - Sistema Administrador 

Este proyecto es el **Sistema Administrativo Web** que sirve como panel de control central para la aplicación móvil y la gestión general de servicios industriales de la empresa **Sertena**.

## Nuestro Equipo
Somos un equipo de **5 integrantes** trabajando en conjunto para brindar la mejor solución tecnológica a Sertena.

## Funcionalidades Principales
El sistema administrativo está diseñado para tener control total sobre las operaciones de la empresa. Algunas de sus funciones principales incluyen:

*   **Gestión de Citas:** Control, asignación y seguimiento de dónde y cuándo se llevarán a cabo las citas de mantenimiento o servicio industrial.
*   **Gestión de Servicios Disponibles:** Administración del catálogo de servicios industriales que Sertena ofrece a sus clientes (mantenimiento, instalación, etc.).
*   **Gestión de Reseñas:** Monitoreo y control de las reseñas y calificaciones que los clientes dejan a través de la aplicación móvil tras recibir un servicio.
*   **Métricas y Rendimiento:** Visualización de ventas, tendencias de ingreso y demanda de servicios a través de un panel (dashboard) interactivo.

## Tecnologías Utilizadas
Para el desarrollo de este panel web hemos utilizado las siguientes tecnologías modernas:

*   **React:** Biblioteca principal para la construcción de interfaces de usuario.
*   **Vite:** Herramienta de empaquetado ultra rápida para el entorno de desarrollo.
*   **Tailwind CSS (v4):** Framework de utilidades CSS para un diseño ágil, completamente responsivo y estilizado.
*   **React Router Dom:** Manejo de la navegación y las rutas de la aplicación (Login, Recuperación, Dashboard, etc.).
*   **@paper-design/shaders-react:** Utilizado para implementar fondos animados de alta calidad y rendimiento con WebGL (efectos de cristal y gradientes fluidos).

## Instalación y Uso Local

1. Clonar este repositorio.
2. Navegar a la carpeta del proyecto (`cd frontend`).
3. Instalar las dependencias:
   ```bash
   npm install
   ```
4. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abrir el navegador en la dirección indicada (usualmente `http://localhost:5173`).
